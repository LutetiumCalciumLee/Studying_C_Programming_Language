# C 언어 학습 요약

## 핵심 기초
- **C 언어 기본**: 컴파일 과정, Visual Studio 설정, 프로그램 구조
- **입출력**: `printf/scanf` 형식 입출력, 서식 지정자 (`%d`, `%f`, `%s`, `%c`)
- **연산자**: 산술 (`+`, `-`, `*`, `/`, `%`), 관계, 논리 (`&&`, `||`, `!`), 대입, 증감 (`++`, `--`)

## 제어문
- **조건문**: `if/else`, 중첩 `if`, `switch-case` (`break` 포함)
- **반복문**: `for` (초기화; 조건; 증감), `while`, `do-while`
- **반복 제어**: `break` (반복 종료), `continue` (이번 반복 건너뛰기), `goto`, `return`

## 자료구조 & 메모리
- **배열**: 1차/2차원 배열, 초기화 `{1,2,3}`, `sizeof`로 크기 계산
- **포인터**: 선언 (`int *p`), 주소 (`&var`), 역참조 (`*p`), 포인터 산술
- **동적 메모리**: `malloc()`, `calloc()`, `realloc()`, `free()` 런타임 할당
- **문자열**: `'\0'`로 끝나는 문자 배열, `strlen()`, `strcpy()`, `strcat()`

## 고급 주제
- **함수**: 선언, 매개변수 (값/참조 전달), 지역/전역 변수, 재귀
- **파일 입출력**: `fopen()`, `fclose()`, `fscanf()`, `fprintf()`, `fread()`, `fwrite()`
- **자료구조**: 배열과 포인터로 스택 구현 (push/pop)
- **포인터 배열**: `char* arr[10]`로 가변 길이 문자열 처리
